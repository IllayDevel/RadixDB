# RadixDB 1.1: проверка выпуска на 100 миллионах строк

[English](RADIXDB_1_1_100M_VALIDATION.md)

Дата: 2026-09-08
Статус: **PASS**

## Идентичность и методика

Принятая серия запросов использовала исходники производительности `12ef5963`,
неизменённую каноническую базу на 100 миллионов строк на NVMe/Btrfs,
`page-cache-level=0`, один исключённый прогрев и пять измеряемых повторов в
каждом из трёх заранее объявленных запусков после перезапуска. Запуски с
монотонным прогревом кэша операционной системы исключались до сравнения.

Тег выпуска `v1.1.0` указывает на коммит
`804027a4ee8426b6f7bd083c6e26a1895603dc38`. Исходники измерения
производительности учитываются отдельно от последующих исправлений
корректности и не выдаются за более новый исполняемый файл бенчмарка.

## Результат

| Сценарий | Медиана кандидата 1.1 | Принятый baseline | Изменение |
| --- | ---: | ---: | ---: |
| Агрегация | 10,150 ms | 9,907 ms | +2,45% |
| Контрольная сумма | 12,007 ms | 11,638 ms | +3,17% |
| Словарь фактов | 572,626 ms | 592,686 ms | -3,38% |
| Полное сканирование | 105,224 ms | 100,299 ms | +4,91% |
| Откат UPDATE | 42,994 ms | 52,568 ms | -18,21% |
| Откат DELETE | 2,285 ms | 3,180 ms | -28,13% |

Все три принятых запуска сохранили 100 000 000 строк, контрольную сумму
`100000000:49734600639880` и digest путей доступа
`499488e7eeca18a91a2ebb763473308e15d4e929a7c0770d933c9fd9bba084d4`.
Пиковые значения RSS составили 563 662 848, 566 497 280 и 551 399 424 байта.
Наибольшее указанное замедление равно 4,91%, что ниже заранее установленной
границы в 1,20 раза.

SHA-256 исполняемого файла выпуска:
`d28acefb30cde0224e5298e67237933e9e117ec7a6e2bd1910a514434a1ae1d2`.
SHA-256 Cargo.lock:
`a2b5a5a1c19da45ad29cdb05ce7d7fbaff40a766ef3727291c7edc89475171cb`.

Каталоги с необработанными результатами не распространяются в публичном
репозитории. Эта компактная запись сохраняет принятые идентификаторы, методику
и значения выпуска.
