# RadixDB 1.2: проверка на базе со 100 миллионами строк

[English](RADIXDB_1_2_100M_VALIDATION.md)

Дата: 2026-09-09
Статус: **PASS**

## Назначение

Проверка подтверждает, что исходная база со 100 000 000 строк остаётся
доступной после изменений серверного, security и reliability слоёв RadixDB
1.2. Это проверка текущей версии, а не повтор междвижкового benchmark: значения
PostgreSQL и более раннего RadixDB из сравнительной таблицы не пересчитывались.

| Метрика | Значение |

| Final RSS | 343,04 MiB |
| Allocated database size | 1,83 GiB |
| Storage/resource errors | 0 |

Проверка сохранила точную cardinality и checksum. Все приведённые значения
относятся к указанному source SHA и этому конкретному NVMe-прогону. Они не
являются SLA, универсальной оценкой ёмкости или результатом PostgreSQL
comparison.

Полный raw bundle хранится вне публичного Git-репозитория. В публичном наборе
зафиксированы его идентичность, условия и принятые итоговые метрики.
