# Документация RadixDB

[English](README.md)

Этот каталог содержит проверенное руководство Astro/Starlight для RadixDB 1.2.
Основным языком является английский, а каждая пользовательская глава имеет
русский аналог. Рядом с текстом находятся публичные примеры, навигационные
метаданные и скрипты проверки.

Официальный сайт проекта — [radixdb.org](https://radixdb.org), адрес поддержки —
[dev@radixdb.org](mailto:dev@radixdb.org), разработку спонсирует компания
[Light Soft](http://light-soft.info/).

Принятые отчёты о быстродействии, размере хранения, потреблении памяти и
надёжности сохранены в [публичном архиве доказательств](public/evidence/README.ru.md).
Руководство и его сборка используют только публичные исходники и принятые
доказательства.

## Локальная разработка

Требуется Node.js 22.12 или новее. Из этого каталога:

```sh
npm ci
npm run build
npm run test:editorial
npm run dev
```

Откройте `/manual/1.2/ru/` или `/manual/1.2/en/` по адресу локального сервера.
`npm run preview` запускает собранный сайт, включая поисковый индекс.
`DOCS_BASE` задаёт другой префикс публикации. Целевая версия документации — 1.2 development;
версия приложения и коммит исходников показываются отдельно.

Проверка публикационного artifact на непустом префиксе:

```sh
DOCS_SITE=https://docs.invalid \
DOCS_ROOT_BASE=/preview/ \
DOCS_BASE=/preview/manual/1.2/ \
npm run test:publication
```

`build:publication` требует те же три переменные и по умолчанию создаёт сайт
в `.site-artifact/`. В него входят версионное руководство, поиск, sitemap,
страница 404 и старые redirect-маршруты; внешнее развёртывание не выполняется.

Внешнее развёртывание остаётся отдельной операцией.
