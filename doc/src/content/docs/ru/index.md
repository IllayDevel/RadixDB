Это руководство в разработке предназначено для **RadixDB 1.2**. Версия
приложения, коммит Git и состояние рабочего дерева каждой сборки указаны внизу
страницы. Известные ограничения приведены рядом с соответствующими командами
и функциями.

## Содержание

Знакомство начинается с локальной базы в клиенте командной строки, продолжается
языком SQL и администрированием, затем переходит к интерфейсам приложений
и серверному программированию. Полный синтаксис и параметры вынесены в справочник.

Руководство следует этому порядку:

1. [Введение](./preface/what-is-radixdb/): назначение, терминология и условные обозначения.
2. [Учебник](./tutorial/getting-started/): первая база, запросы, связи и транзакции.
3. [Язык SQL](./sql/syntax/): типы, выражения, запросы, индексы и навигационные ссылки.
4. [Администрирование](./administration/installation/): установка, настройка, хранение и восстановление.
5. [Клиентские интерфейсы](./clients/overview/): встроенный Rust API, TCP-клиент и ORM.
6. [Серверное программирование](./programming/pl-sql/): процедурный SQL, подпрограммы, триггеры, задания и trusted native extensions.
7. [Справочник](./reference/sql/): команды SQL, программы и параметры конфигурации.
8. [Внутреннее устройство](./internals/overview/): исполнение запросов, хранение и протокол.

## Версия и проверка

Целевая версия документации — 1.2 development. Версия приложения, коммит Git
и состояние рабочего дерева показываются отдельно, чтобы сборка документации
не выдавала разрабатываемый движок за выпущенный. Главы процедурного SQL, ACL и
native extensions описывают текущие границы 1.2, включая явно указанные
ограничения. Native packages выполняются in-process и требуют operator trust;
начните с [эксплуатации extensions](./administration/extensions/).
