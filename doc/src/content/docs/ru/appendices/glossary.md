---
title: Глоссарий
description: Термины, используемые в руководстве RadixDB.
---

Глоссарий устанавливает терминологию руководства.
Он не определяет полный контракт хранения или транзакций.

| Термин | Значение |
| --- | --- |
| Корень базы (database root) | Каталог с постоянным состоянием базы данных. |
| Каталог (catalog) | Метаданные базы, описывающие объекты, например таблицы и индексы. |
| Транзакция (transaction) | Единица работы с определённой границей фиксации или отката. |
| MVCC | Многоверсионное управление конкурентным доступом; чтение версий определяется правилами видимости. |
| WAL | Журнал предзаписи, используемый процедурами надёжного сохранения и восстановления. |
| Контрольная точка (checkpoint) | Граница восстановления, точное значение которой задаёт контракт хранения. |
| Бюджет кэша (cache budget) | Настроенное ограничение кэша, а не всей памяти процесса. |
| RSS | Объём памяти процесса, находящейся в физической памяти. |
| Внешний ключ (FK) | Связь, ограниченная ссылкой на ключ в другой или той же таблице. |
| Навигационная ссылка (navigable reference) | Нотация запросов RadixDB для перехода по объявленным связям. |
| ORM | Объектно-реляционное отображение: интерфейс приложения, связывающий записи и операции базы. |
| ACL | Список управления доступом; модель объектных прав, описанная в главах безопасности. |
| Invoker / definer | Контекст вызывающего или владельца, используемый при проверке прав подпрограммы. |
| Принято (accepted) | Поведение проверено приёмочными проверками реализации, а не только описано в плане. |

Ключевые слова SQL, ключи конфигурации и идентификаторы API не переводятся.
Конкретные лимиты, правила изоляции и гарантии безопасности описываются
в соответствующих главах, а не в этих кратких определениях.
