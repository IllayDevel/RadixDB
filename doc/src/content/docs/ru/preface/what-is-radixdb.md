---
title: Что такое RadixDB?
description: Назначение и режимы работы RadixDB.
---

RadixDB — открытая SQL-база данных, написанная на Rust. Она хранит связанные
данные в таблицах и предоставляет приложениям запросы и транзакции.
Движок может работать внутри Rust-приложения либо отдельным процессом
в качестве TCP-сервера.

Хранение сочетает изменяемые версии строк с неизменяемыми сжатыми колоночными
блоками. Это позволяет выполнять транзакционные изменения и колоночное
сканирование в одной базе. Бюджеты кэшей управляют частью потребления памяти;
они не требуют помещать каждую базу целиком в RAM.

## Режимы работы

Встроенное приложение открывает базу через Rust API. Локальный клиент
командной строки использует этот режим; с него начинается учебник.
Сервер владеет базой в своём процессе и принимает клиентские подключения.
Локальный CLI не является TCP-оболочкой сервера.

Далее руководство знакомит с навигацией по внешним ключам, клиентской ORM,
процедурным программированием и trusted native extensions. Эти возможности
решают разные задачи: запись запросов, доступ приложения к данным, серверная
логика и bounded предметные types, functions и index behavior.

Functions, procedures, triggers и extensions образуют практический базовый
набор, а не обещание drop-in-совместимости с PostgreSQL. Из этих механизмов
можно собирать более специализированное поведение базы, хотя синтаксис или
порядок работы иногда будет менее прямым, чем в более крупной системе.

## Версия и происхождение

Руководство описывает реализованные границы RadixDB 1.2. Опубликованные
результаты производительности и восстановления относятся к проверенным
коммитам и нагрузкам, а не автоматически к любой установке или следующей версии.

RadixDB распространяется под лицензией Apache License, Version 2.0.

Официальный сайт проекта — [radixdb.org](https://radixdb.org). Разработку
спонсирует компания [Light Soft](http://light-soft.info/), поддержка пользователей
доступна по адресу [dev@radixdb.org](mailto:dev@radixdb.org).
