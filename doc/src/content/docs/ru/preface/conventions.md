Команды оболочки и SQL показаны в отдельных блоках кода. Команды оболочки
выполняются в терминале, SQL вводится в клиенте базы. Приглашения ко вводу
не показаны, чтобы они не попадали в скопированные команды.

Ключевые слова SQL записаны прописными буквами, идентификаторы примеров —
строчными. Команда заканчивается точкой с запятой. Текст в кавычках, например
`'Alice'`, является данными, а не идентификатором. SQL `NULL` обозначает
отсутствующее значение, а не пустую строку.

## Примеры и результаты

Английская и русская версии используют одинаковые идентификаторы, учебные
данные и исполняемые SQL-файлы. Переводятся объяснения, но не команды.
Таблицы результатов показывают ожидаемые значения без рамок терминала.
Когда порядок строк существенен, используется явный `ORDER BY`.

Переменные оболочки, например `tutorial_dir`, должны сохраняться на время
упражнения. Не подставляйте в учебные команды путь к рабочей базе.
База из одного упражнения не является резервной копией другой базы.

## Версии и ограничения

Заголовок указывает целевую версию документации. Сведения о сборке отделяют
её от версии манифеста приложения и коммита исходного кода. Явное ограничение
означает, что поддерживаемое в 1.2 поведение уже, чем возможности раздела;
поведение, описанное только в плане, не входит в пользовательский контракт.

Ограничения разделяются на пределы реализации, настройки и измеренные размеры
нагрузки. Результат измерения не является универсальной гарантией ёмкости.
