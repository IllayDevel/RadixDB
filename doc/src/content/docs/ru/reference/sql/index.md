Справочник описывает поверхность команд SQL, проверенную для RadixDB 1.2 на
ревизии `23bf35df011aae6816d77578be96074b02bc363c`. Для каждой команды приведены
принимаемый синтаксис, результат, поведение в транзакции, ошибки, права и
исполняемый пример. Авторитетным перечнем поддерживаемых, ограниченных и
отклоняемых контрактов остаётся [матрица покрытия](../../appendices/compatibility/).

## Запросы и изменение данных

- [SELECT](./select/) читает и объединяет строки.
- [INSERT](./insert/) добавляет строки и обрабатывает поддерживаемые конфликты.
- [UPDATE](./update/) изменяет подходящие строки.
- [DELETE](./delete/) удаляет подходящие строки.

## Схема и метаданные

- [CREATE TABLE](./create-table/), [ALTER TABLE](./alter-table/) и
  [DROP TABLE](./drop-table/) управляют таблицами.
- [CREATE INDEX](./create-index/), [ALTER INDEX](./alter-index/) и
  [DROP INDEX](./drop-index/) управляют вторичными структурами доступа.
- [DESCRIBE](./describe/) и [SHOW](./show/) читают метаданные каталога.

## Управление транзакциями

- [BEGIN](./begin/), [COMMIT](./commit/) и [ROLLBACK](./rollback/) задают границы
  явной транзакции.
- [SAVEPOINT](./savepoint/) и [RELEASE SAVEPOINT](./release-savepoint/) создают
  точки частичного отката и удаляют их.
- [SET](./set/) изменяет поддерживаемое значение по умолчанию для движка.

Идентификаторы без кавычек не зависят от регистра. Квадратные скобки в описании
синтаксиса обозначают необязательную часть, фигурные скобки обозначают выбор;
они не являются литералами SQL. Без ORDER BY порядок строк не определён. Штатный
TCP-сервер использует bootstrap-сессию root, а embedded-хосты с обычными
Principal обязаны применять права, указанные на страницах команд.
