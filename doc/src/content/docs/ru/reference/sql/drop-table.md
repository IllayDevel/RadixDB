`DROP TABLE` удаляет существующую таблицу.

## Синтаксис

```text
DROP TABLE [IF EXISTS] table_name
```

## Описание

Команда удаляет отношение, его строки и локальные метаданные индексов. IF EXISTS
подавляет только ошибку отсутствующего объекта.

## Параметры

`table_name` является неквалифицированным именем таблицы в текущем пространстве
каталога.

## Результат

Успех возвращает командный результат без строк. IF EXISTS также успешен, когда
подходящей таблицы нет.

## Поведение в транзакции

DROP TABLE транзакционен. До COMMIT другие сессии сохраняют корректное
зафиксированное представление, а ROLLBACK оставляет таблицу.

## Ошибки и ограничения

Без IF EXISTS отсутствие таблицы является ошибкой. Зависимости и ссылочные
ограничения могут запретить удаление. Команда не удаляет другую базу или
посторонние файлы.

## Права

Эффективный Principal должен владеть таблицей; сессии также нужен CONNECT.

## Пример

```sql
CREATE TABLE ref_drop_table (id INTEGER PRIMARY KEY);
DROP TABLE ref_drop_table;
SHOW TABLES;
```
